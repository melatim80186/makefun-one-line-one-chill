# One Line, One Chill

A single sentence of horror, written to frighten a reader in one breath. The line works by withholding: it states a plain, verifiable fact — tomorrow's newspaper — and then leaves the one detail that matters blank, so the dread keeps growing after the sentence ends. No gore, no mirror, no doll, no basement — just an ordinary object carrying an impossible fact, with the last word landing the blow.
